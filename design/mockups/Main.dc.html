The handoff packet

Pick it up in an afternoon, not a week.

AI-assisted projects already carry their own record of intent. Brainchild asks you to package it, so the next person and their AI tools can start where you stopped.

  1. 01

    What works

    The playable parts, and how to build and run them.

  2. 02

    What's broken

    Known bugs, dead ends, and fixes you already tried.

  3. 03

    What I was going for

    The vision: the feel, the endgame, what you'd build next.

  4. 04

    Agent context

    Your CLAUDE.md, AGENTS.md or prompt notes describing the architecture.

  5. 05

    Asset provenance

    What was generated, with which tool, and what was made by hand.

  6. 06

    A license

    Required. No license means nobody can legally continue it.

House rules

  • >Free to play and use, always. No paywalls, no loot boxes.
  • >Games and apps must run in the browser, built or checked on our side. No mystery downloads.
  • >Mods ship as source with install notes and the base game version, and are scanned before listing.
  • >Open license for code and assets before the "up for adoption" label.
  • >Credit carries forward. Every maintainer stays on the lineage.
  • >No sexually explicit content, including mods. Mature projects are labelled and hidden by default.
  • >Spot something wrong? Use Report. A moderator reviews every report.
